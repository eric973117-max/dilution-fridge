# data/ · 运行时数据

这个目录放**运行时数据**，和 `content/` 里的**静态内容**分开：

| | 放什么 | 什么时候加载 |
| --- | --- | --- |
| `content/` | 章节文案、规格、几何参数 | 构建期就定下来，直接 import |
| `data/`（这里） | 实验曲线、实测读数、机器状态等时间序列 | 运行时通过 `src/feed.js` 取 |

约定（见 `src/feed.js` 顶部注释与 `docs/PLAN.md` §4）：

- 一个文件一条序列，JSON 数组，每项形如
  `{ "t": 0.0, "channel": "readout", "value": 1.23, "unit": "µV", "source": "实验室 2026-08" }`。
- 数据来源、测量条件、论文出处必须写进 `meta` 字段或同目录的说明文件；
  **论文插图不能直接用**，只能引用数值并自己重绘（见 `LICENSES.md`）。
- 现在（P0）还没有数据文件：接真实数据时按上面的形状放进来，用 `?feed=replay` 打开回放。
